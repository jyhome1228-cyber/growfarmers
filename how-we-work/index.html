HOW WE WORK

지원사업을 찾아 진행하거나,
바로 의뢰할 수 있습니다.

지역 농업기술센터에서 지원사업을 먼저 확인할 수도 있고, 지원사업 없이 필요한 디자인·웹·패키지 작업을 바로 진행할 수도 있습니다. 현재 상황에 맞는 방법을 선택하면 됩니다.

01 / LOCAL SUPPORT

내 지역 농업기술센터에서
지원사업을 먼저 찾아보세요.

농촌진흥청의 지방농촌진흥기관 목록에서 지역별 농업기술센터를 확인하고 각 센터 홈페이지로 이동할 수 있습니다. 아래에서 도와 시·군을 선택하면 센터 이름, 지도 검색, 지원사업 검색으로 바로 이어집니다.

02 / SUPPORT PROJECT

지원사업을 이용한다면
이 순서로 확인하면 됩니다.

01

지역 센터 확인

농장 소재지의 농업기술센터 홈페이지와 공지사항을 먼저 확인합니다.

02

지원사업·시범사업 찾기

지원사업, 시범사업, 농업인 지원, 가공·유통·브랜드·마케팅 관련 공고를 확인합니다.

03

공고문과 수행 범위 확인

신청 의향이 있거나 선정된 경우 공고문·협약서·사업비 사용 기준을 보내주시면 실제 수행 가능한 과업과 산출물을 확인합니다.

04

디자인·마케팅 과업 수행

공고와 협약에서 허용되는 범위 안에서 브랜딩, 패키지, 촬영, 상세페이지, 홈페이지·쇼핑몰, 홍보·마케팅 디자인 등을 진행합니다.

GROW FARMERS

선정되셨거나 신청을 준비하고 있다면
공고문을 보내주세요.

디자인·마케팅 분야의 수행이 필요한 사업이라면 사업 기준에 맞춰 과업, 결과물, 일정과 견적을 정리합니다. 지원사업의 선정 여부를 보장하거나 신청을 대행하는 방식은 아닙니다.

03 / DIRECT PROJECT

지원사업 없이
직접 진행해도 됩니다.

공고 일정이나 선정 결과를 기다리지 않고 필요한 작업을 바로 정해 진행할 수 있습니다. 브랜드, 홈페이지, 쇼핑몰, 상세페이지·촬영, 패키지·양산, 출판물 중 필요한 항목만 선택해 견적과 일정을 협의합니다.

상담범위·견적계약디자인·구축·제작납품·운영
직접 프로젝트 상담하기
